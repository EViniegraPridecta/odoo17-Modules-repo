# Duplicate Detector for Odoo

Prevents creation of duplicate Contacts and Products in Odoo.

## Features
- Blocks duplicate Contacts by email or phone
- Blocks duplicate Products by name or barcode
- Works on create and update
- No configuration required

## Supported Versions
- Odoo 17

## Installation
1. Clone or download this repository
2. Copy `duplicate_detector` into your Odoo addons directory
3. Restart Odoo
4. Go to Apps → Update Apps List
5. Install **Duplicate Detector**

## Limitations
- Not supported on Odoo Online (SaaS)
