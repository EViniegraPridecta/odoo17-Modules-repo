Duplicate Detector

Prevent duplicate contacts and products

Features

  • Blocks duplicate Contacts by email or phone
  • Blocks duplicate Products by name or barcode
  • Works on record creation and update
  • No configuration required

Supported Versions

  • Odoo 17

Notes

This module works on self-hosted Odoo and Odoo.sh.
It is not supported on Odoo Online (SaaS).
